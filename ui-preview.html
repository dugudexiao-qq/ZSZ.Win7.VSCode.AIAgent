点右上角 ··· 打开菜单，选 长期要求 管理；Show Effective Prompt 查看每次请求真正注入的内容。硬约束优先，模型绕不过。

过程可见 · 1000 s 超时

状态栏显示阶段文案、秒表计时、字数与进度条，Stop 随时取消。需要你确认时文字与提示变黄（暂停等待确认），完成后变绿，出错变红。HTTP 有「无数据 + 整体墙钟」双超时，默认 1000 s；诊断命令独立用 15 s。

「思考过程」面板只在端点真的返回 reasoning_content 等字段时出现，不编造思维链。

文件与命令

Import 支持 txt / md / csv / docx / xlsx（零依赖解 ZIP，自动识别 GBK）；Save 导出最后一次回答。

PowerShell/CMD v0.3.2 起默认开启，但每条命令仍需弹窗确认 + 白名单前缀校验。执行走参数数组 + -EncodedCommand 规避转义，stdin 直接 ignore，墙钟/静默双超时用 taskkill /T /F 杀整棵进程树。

设置端口（内网机）

扩展不内置任何地址或端口。端口写在 win7Agent.baseUrl 里，首次请填完整地址如 http://主机:端口/v1。命令面板 Set Server URL / Port 或点顶部 服务地址 / 端口 按钮填写；设置过完整地址后，之后才可只填 8080 改端口。

若 VS Code 1.70.2 设置界面显示 No settings found：v0.3.2 已补齐 configuration.type；也可直接改 settings.json，完全不依赖设置 UI。

随时卸载

code --uninstall-extension dugudexiao.win7-ai-agent

左侧按钮只做界面演示：Send 会在本地追加气泡，其余弹说明，不发起任何请求。
